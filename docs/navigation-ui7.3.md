# UI 7.3 화면 일관성 수정

달력·반복 일정의 독립 셸을 공통 AuthLayout으로 교체하여 오른쪽 메뉴를 복구한다. 오늘·달력·반복 일정은 공통 WorkspaceTabs를 사용한다. 계정·재인증·이메일·휴대폰 보조 화면도 공통 메뉴를 유지한다. 가족·계정 탭의 높이·선택색·간격을 통일한다. 아이 내 하루/일정 메뉴를 실제 연결된 기기 경로로 수정한다.

이 패치는 DB·인증·가족 등록 권한을 변경하지 않는다. 새 가족 연결 기능은 별도 PR 4의 DB 변경 승인 후 반영 대상이다.

검증: 기존 기능 회귀와 운영 경로 16곳 × 320/390/768/1024/1440px의 브랜드·메뉴·바깥 스크롤 검사.
