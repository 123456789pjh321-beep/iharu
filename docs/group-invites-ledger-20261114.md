# 가계부·로그인·그룹 초대 개선 (2026-11-14)

## 동작

- 가계부 월 변경 시 “예산 불러오는 중” 문구를 표시하지 않습니다. 다른 달의 예산을 임시로 보여주지 않으며, 불러오기 실패 시 재시도는 유지합니다.
- 가계부 화면 아래의 고정 등록 버튼을 제거했습니다. 날짜를 누른 뒤 추가하거나 내역 화면에서 추가할 수 있습니다.
- 계정 확인, 자료 조회, 지연 로딩이 이어질 때 공통 로딩 표시를 계속 유지합니다. 달력의 기존 배치 구조는 그대로 사용합니다.
- 일반 로그인은 시간표로 이동합니다. 초대 링크를 열었던 브라우저에서는 시간표의 ‘받은 그룹 초대’에서 명시적으로 수락합니다. 보안 재인증·로그인 수단 연결은 해당 계정 작업을 계속합니다.
- 그룹마다 최신 초대 링크 한 개만 남습니다. 재발급 시 이전 링크를 삭제하며, 최신 링크는 24시간 동안 여러 명이 사용할 수 있습니다.
- 모든 일반 구성원이 초대할 수 있습니다. 내보내기는 호스트만 할 수 있습니다. 호스트와 구성원 모두 자유롭게 나갈 수 있습니다.
- 현재 구조는 1인 1그룹입니다. 다른 그룹 초대 수락 시 기존 연결 종료를 확인한 뒤 새 그룹으로 원자적으로 이동합니다.
- 호스트가 나가거나 이동하면 먼저 가입한 일반 구성원이 승계합니다. 기존 아이디 계정만 남은 과거 그룹에서는 남은 계정의 가입 순서로 승계하며 일반사용자 인증 규칙은 유지합니다.
- 나가기·내보내기는 해당 그룹의 초대 링크를 폐기합니다. 재참여하려면 남은 구성원이 새 링크를 발급해야 합니다.
- 본인 작성 일정·가계부·메모는 보존하고 새 그룹에 본인 자료만 공유합니다. 이전 그룹 다른 사람의 자료, 기존 대화방과 대화는 새 그룹에 옮기지 않습니다. 호스트도 다른 사람 원본을 수정·삭제할 수 없습니다.
- 이미 참여한 그룹 수락은 중복 변경 없이 성공합니다. 오래된 구성원 버전은 거부하며, 재발급·동시 수락·나가기는 트랜잭션으로 정렬합니다.

## 검증

- 로컬 전체 자동 테스트 349개 및 타입 검사·빌드 통과.
- 실제 PostgreSQL에서 동시 초대 재발급, 중복 수락, 비공개 함수 접근 차단 통과.
- 브라우저 검증 통과: 초대·문맥 로그인 20개, 초대·가계부·단일 로딩 집중 검증 11개, 타임라인·대화 5개(중복 제외 31개). 코드 기준 커밋 f5024a02f72edca273b74aa3afa027f64cde4978, PR #102. 추가 회귀 목록의 등록 버튼·로딩 요소·로그인 복귀 기대값도 새 정책에 맞춰 갱신했습니다. 전체 브라우저 목록의 완전 통과를 의미하지는 않습니다.
- 운영 DB에 그룹당 링크 한 개의 고유 인덱스 적용 및 내부 함수 직접 실행 차단 확인.
- 운영 데이터로 테스트 계정을 생성하거나 개인 자료를 복제하지 않습니다.

- TimeTree: 호스트가 나가면 다음으로 가입한 구성원에게 권한 승계. https://support.timetreeapp.com/hc/en-us/articles/115000038561-About-the-creator-admin

## 적용

두 SQL 경로는 동일한 마이그레이션 사본입니다. 사용하는 마이그레이션 경로에서 한 번만 적용합니다. 운영 DB는 이번 작업에서 적용했으므로 수동으로 중복 실행하지 않습니다.
