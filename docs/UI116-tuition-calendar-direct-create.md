# UI116 · 학원비 달력 날짜에서 바로 등록

학원비 달력의 날짜 칸을 누르면 학원비 등록 화면이 바로 열린다. 선택한 날짜를 첫 납부일에 넣으며, 한 번 납부로 바꿔도 같은 날짜를 유지한다. 빈 날짜·기존 내역이 있는 날짜 모두 동일하게 동작하고 마우스·터치·키보드 Enter로 접근할 수 있다.

등록 화면을 닫으면 선택한 날짜의 가계부 내역을 표시한다. 저장 전에는 학원비가 생성되지 않으며 저장 후 월 합계와 해당 날짜 금액을 갱신한다. 월 이동과 화면별 인원 필터 저장은 유지한다.
