# UI117 · 간결한 상단 타이틀바와 시간표

앱 작업 화면의 타이틀바는 로고 아이콘만 표시한다. 보조 기기에는 기존 ‘아이하루’ 링크 이름을 유지한다. 시간표의 현재 시간 버튼과 사용 안내 버튼을 타이틀바로 옮겼다. 현재 시간 버튼을 누르면 시간표가 현재 시각으로 이동하며 시계는 계속 갱신된다. 다른 메뉴로 이동하면 시간표 시계는 제거되고 사용 안내는 해당 계정의 안내를 연다.

시간표 본문의 ‘주간 시간표’, ‘여러 명 선택 가능’, ‘매주 반복 · N개 일정’ 문구와 빈 요약 행을 제거했다. 현재 진행 중인 일정이 있으면 해당 안내는 유지한다. 시간표 필터 펼치기·접기 화살표를 없애고 좁은 화면에서는 구성원 버튼이 줄바꿈되어 모두 선택 가능하다. 다중 선택과 첫 화면 저장 기능은 유지한다.

사용 안내는 처음 접속할 때도 상단 버튼으로 제공한다. 본문의 환영 배너·다시 보기 행은 제거하고, 전체메뉴의 다시 보기와 안내 완료·ESC 닫기·초점 복원은 유지한다. 공개 서비스·로그인 화면의 브랜드는 변경하지 않는다.
