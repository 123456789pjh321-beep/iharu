# UI111 · 달력 일정 시작일–종료일

- 달력 등록에서 시작일·종료일을 항상 표시한다. 두 날짜의 기본값은 등록을 시작한 당일(달력에서 다른 날짜를 눌렀으면 그 날짜)이다. 기존 기록은 종료일이 없으면 시작일과 같은 날짜로 연다.
- 한 번의 일정은 `date`부터 `endDate`까지 양 끝 날짜를 포함한다. 시간은 첫날 시작 시각과 마지막 날 종료 시각이다. 종일 일정과 자정을 넘는 일정 모두 지원한다.
- 반복의 `untilDate`는 마지막으로 새 반복을 시작할 수 있는 날짜로 유지한다. `endDate`는 첫 일정의 길이를 정한다. 월말·윤년 보정, 반복 종료일 이후까지 이어지는 마지막 일정, 겹치는 반복의 일간 시간 구간을 지원한다.
- 달력 기간 선택은 시작→종료→선택 완료. 당일/1박 2일/2박 3일/일주일 빠른 선택, 취소, 키보드 이동을 제공한다. 반복 종료 설정은 별도 필드다.
- 저장·목록 조회를 함께 수정해 이전 달에 시작한 일정도 현재 달에 표시한다. 월간·주간은 기존 연결 막대로, 일간은 해당 날짜의 시간으로 잘라 표시하며 원본을 편집한다.
- 시작 알림은 반복 시작일에만 계산한다. 이어지는 날짜마다 중복 알림을 생성하지 않는다.
