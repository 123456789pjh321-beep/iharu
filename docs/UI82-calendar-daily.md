# UI82 — 달력 일간 보기·구성원 표시·연말 종료일

2026-11-08. UI81의 시간 눈금 표, 전체 일정, 시간순 정렬을 그대로 이어갑니다.

- 달력 보기: 월간 / 주간 / 일간. 일간에서는 선택한 날짜를 직접 지정하고 하루씩 이전·다음 이동, 오늘 복귀가 가능합니다.
- 일간 일정에도 시간표와 같은 00:00~24:00 시간축과 15분 칸을 사용합니다. 입력 시각에 맞는 위치와 기간에 비례한 높이, 겹치는 일정의 나란한 표시를 유지합니다.
- 일간 카드마다 구성원 이름을 표시하며, 가족 전체 일정은 `전체`로 표시합니다. 종일 일정도 구성원을 표시합니다.
- 기존 검색·구성원 필터를 일간에 적용합니다. 전체 일정은 각 구성원 필터에 함께 나타납니다.
- 빈 시간 클릭 등록, 카드 수정·삭제는 월간·주간·시간표와 같은 원본을 사용합니다. 기존 가족 접근 범위와 작성자 편집 권한을 유지합니다.
- 새 반복 일정과 매월 학원비의 반복 종료일은 시작일/첫 납부일이 속한 해의 12월 31일로 기본 설정합니다. 종료일을 직접 수정하지 않았다면 시작 연도 변경에 따라 갱신하며, 직접 지정한 종료일과 기존 저장 자료(종료일 없음 포함)는 유지합니다.
- 일간은 공통 시간표 컴포넌트를 재사용하되 날짜·필터 도구가 중복되지 않게 표시합니다. 별도 DB 변경은 없습니다.
