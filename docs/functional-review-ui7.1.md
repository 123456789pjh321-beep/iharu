# 아이하루 UI 7.1 — 기능 검토 및 통합 테스트 작업실

## 바로 테스트

운영 주소의 `/test/today`에서 가입·이메일 인증·보호자 확인 없이 시작한다. 로그인 화면의 `인증 없이 기능 테스트`도 같은 작업실로 연결한다. 이 모드의 데이터는 별도 키 `iharu:test-workspace:v1`로 해당 브라우저에만 저장하며, 운영 API·가족 DB·인증 세션에 접근하지 않는다. 실제 개인 정보 대신 예시 데이터를 사용한다. 다른 기기와 동기화되는 운영 서비스의 완성 여부를 증명하는 모드는 아니다.

## 기능별 검토

| 메뉴 | 테스트 작업실에서 확인하는 동작 | 운영 연동의 확인 범위 |
|---|---|---|
| 오늘 | 선택한 날짜·아이별 일정, 도착 수, 대화 수, 미납 장부 합계, 테스트 진행 체크리스트 | 실제 세션·공유 범위는 기존 정책 유지 |
| 달력 | 월 이동, 날짜 선택, 일정 추가·수정·삭제 | 서버 일정 API는 기존 구현 유지. 공휴일 외부 API는 별도 확인 |
| 등하원 | 도착 후 출발, 중복 기록 방지, 기록 취소, 알림·활동 기록 연결 | 실제 저장·다중 보호자 충돌은 기존 서버 테스트 대상 |
| 반복 일정 | 요일별 계획 CRUD, 7일 일정 생성, 같은 반복 계획 중복 생성 방지 | 테스트 데이터로 동작 |
| 가족 대화 | 아이별 방, 보호자·아이 역할, 글·그림 전송 및 삭제 | 실제 Realtime·푸시 발송은 별도 연동 대상 |
| 가족 관리 | 아이 CRUD, 보호자 초대·승인·해제, 공유 범위 조정, 보호자 심사 상태 변경 | 심사 상태 변경은 테스트 시뮬레이션. 실제 보호자 승인 권한을 부여하지 않음 |
| 기기 연결 | 6자리 번호 발급·만료·일치 검증·연결·해제, 아이당 2대 제한 | 현재 브라우저에서의 연결 시뮬레이션. 실제 장치 쿠키나 세션 발급 없음 |
| 위치 | 집·학교·학원 가상 위치 전송·공유 중지 | 실제 GPS·지도·자동 위치 수집 미구현/미검증 |
| 학원비 | 장부 CRUD, 금액 합계, 납부 표시·취소 | 실제 결제·송금 없음. 운영 서버 학원비 기능 완성으로 간주하지 않음 |
| 알림·기록 | 활동에서 생성된 알림, 읽음·안 읽음, 유형·날짜·내용 검색 | 이메일·SMS·푸시 외부 발송 없음 |
| 내 계정 | 가상 이름 저장, 테스트 데이터 초기화, 글꼴·테마·동작 선호 | 실제 비밀번호·OAuth·연결 해제·인증 정책 변경 없음 |
| 아이 화면 | 큰 버튼으로 등하원·대화·일정·위치 테스트 이동 | 가상 아이 역할만 사용 |

## 화면 통일

상단 공통 헤더와 오른쪽 메뉴, 모바일 하단 메뉴를 재사용한다. 폼·카드·대화상자·오류·빈 상태를 같은 블루/네이비 토큰으로 표현하고, 기존 보호된 가족·계정·일정 메뉴의 카드와 입력창도 통일한다. 글꼴 3종(Pretendard / Noto Sans KR / Manrope), 큰 글씨, 밝은/어두운 테마, OS 및 사용자 움직임 줄이기 설정을 이어서 사용한다. 테스트 작업실은 별도 지연 로딩해 일반 화면의 초기 코드에 포함하지 않는다.

## 검증 기준

- 테스트 저장소 직렬화/복구, 입력 오류, 등하원 순서, 반복 중복, 연쇄 삭제, 메시지·학원비·기기 연결 단위 검사
- 운영 API를 차단한 브라우저에서 로그인 없이 CRUD·메뉴 이동·새로고침·알림 연계 검사
- 전체 테스트 메뉴 320/390/768/1024/1440px 가로 넘침 검사 및 큰 글씨 재배치 검사
- 기존 단위/API·실제 PostgreSQL 격리·운영 인증·브라우저 회귀 검사 유지
- 배포 후 운영 API 상태와 테스트 작업실 진입·화면·저장 동작 확인

브라우저 저장이 차단되거나 공간이 부족하면 화면에 안내하고 현재 화면에서만 동작한다. 저장 데이터가 손상됐거나 버전이 맞지 않으면 예시 상태로 복구한다. 테스트 아이 삭제는 해당 아이의 테스트 일정·대화·학원비·기기·가상 위치에만 적용한다.
