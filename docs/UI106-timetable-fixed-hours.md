# UI106: 시간표 06:00–24:00 고정

- 주간 시간표는 일정 유무와 가족 구성원 필터에 관계없이 오전 6시부터 밤 12시(24:00)까지 표시한다.
- 마지막 눈금은 정오와 구분할 수 있도록 `밤 12`로 표시한다. 기존 일정 칸 하단 마감선과 시간 열의 선 없는 디자인을 유지한다.
- 06:00 경계에 걸친 일정은 보이는 부분만 배치하고 원본 시작·종료 시각은 그대로 보존한다. 06:00 이전에 끝난 일정은 이 시간 범위의 표에 배치하지 않는다.
- 달력 일간 보기의 시간 범위 계산과 저장된 일정 자료는 변경하지 않는다. DB migration 없음.
- 서비스 활용방법과 공지의 기존 자동 범위 안내를 고정 범위로 수정한다.
- 검증: 경계 일정의 배치·겹침·원본 비변형, 빈 시간표, 늦은 밤 일정, 타입 검사, 배포 빌드. 브라우저 시나리오는 새 눈금에 맞춰 갱신하며 실제 기기 확인 여부는 별도 보고한다.
