# UI80 — 월별 학원비 · 결제자 · 메뉴 순서 · 상단 밝기

기준: UI79 운영 커밋 `b70091df6ed1c66d9d60d8e5b82ccdcc3c79426c`.

- 학원비 편집기에 한 번 납부/매월 납부, 첫 납부일, 결제할 부모, 선택 가능한 반복 종료일을 추가했습니다. 수강 대상 가족 구성원과 결제자는 별도 항목입니다.
- 매월 납부는 첫 납부일의 일자를 기준으로 표시합니다. 29~31일이 없는 달은 말일을 사용하며 윤년을 반영합니다. 실제 카드 결제나 자동 이체를 실행하는 기능은 아닙니다.
- 납부 상태는 항목·월별로 별도 저장합니다. 11월 완료가 12월 완료로 이어지지 않습니다. 작성자 또는 현재 연결된 지정 결제자가 해당 월의 납부 표시를 변경할 수 있고, 금액·반복 조건 편집은 작성자만 가능합니다. 반복 조건 수정·삭제는 전체 반복에 적용합니다.
- 기존 일회 학원비와 납부 완료 기록은 보존합니다. 기존 결제자가 가족에서 나가면 권한이 즉시 없어지며 다음 편집 시 현재 부모를 다시 선택합니다.
- 자녀는 학원비 메뉴·오늘 요약을 볼 수 없습니다. 직접 URL은 오늘로 이동하며, 서버 목록에서도 학원비를 제거하고 상세·작성·수정·삭제·납부 표시 요청을 차단합니다.
- 하단 메뉴: 오늘 → 달력 → 대화 → 위치 → 더 보기. 학원비는 부모의 더 보기와 오늘 화면에서 엽니다.
- 오늘 화면: 오늘 일정 → 대화 → 위치 → 학원비. 자녀는 앞의 세 영역만 표시합니다. 학원비에는 이번 달 합계·미납 합계와 최대 3개 항목을 표시합니다.
- 상단 톱니바퀴 팝업 대신 밝게/어둡게 버튼을 바로 표시하고 기기별 선택을 유지합니다. 큰 글씨 토글·저장된 큰 글씨 상태와 글꼴 선택을 제거하고 노토 산스로 고정했습니다. 브라우저 자체 확대와 기기의 움직임 줄이기는 계속 지원합니다.

검증 범위: 타입/빌드, 단위/API, 실제 PostgreSQL 동시 납부·권한 검증, 브라우저의 반복 학원비·다른 부모의 납부 표시·자녀 차단·메뉴 순서·밝기 유지·모바일 화면 검사.

운영 마이그레이션은 `db/migrations/20261107143710_recurring_tuition_parent_visibility.sql`입니다. 애플리케이션 배포 전에 적용하며, 사설 스키마/RLS/실행 권한을 유지합니다. 새로운 함수가 기존 함수에 위임하므로 관련 없는 일정·대화·가족 기능은 기존 경로를 유지합니다.

삭제 파일: 없음. 수정·추가 파일 목록은 배포 ZIP의 `PATCH-FILES.txt`에 기록합니다.
