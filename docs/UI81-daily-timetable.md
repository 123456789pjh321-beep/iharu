# UI81 — 시간표 · 가족 전체 일정 · 시간순 정렬

UI80 운영 커밋 80ef511515873b1d916ece1dc06d012dfa0f3154를 기준으로 추가합니다.

- 하단 메뉴: 오늘 → 시간표 → 달력 → 대화 → 위치 → 더 보기. 시간표 경로는 /timetable입니다.
- 시간표는 달력의 EVENT/REPEAT 원본을 조회합니다. 새 저장소나 사본을 만들지 않으므로 양쪽의 등록·수정·삭제는 같은 항목에 적용됩니다. 기존 작성자 편집 권한도 동일합니다.
- 날짜 선택, 7일 이동 바, 전일/다음 날, 오늘로 복귀, 좌우 드래그와 슬라이드 효과를 제공합니다. OS의 움직임 줄이기 설정을 따릅니다.
- 종일 일정은 위에 모으고 시간 일정은 시작 → 종료 → 제목 순으로 정렬합니다. 오늘 화면, 달력, 시간표, 일정 등록창의 그날 목록, 반복 일정 목록에 공통 정렬을 적용합니다. 여러 날짜를 표시하는 목록은 날짜가 우선합니다.
- 시간표는 00:00~24:00의 고정 시간축과 15분 눈금 표입니다. 일정의 시작 분에 맞춰 세로 위치를, 지속 시간에 비례해 높이를 배치하며 겹치는 일정은 옆 열에 배치합니다. 빈 시간 칸을 누르면 해당 시각으로 등록창이 열립니다. 시간표 카드에는 시간 범위, 구성원, 제목, 장소와 반복 여부를 표시합니다. 한국 시간 기준 진행 중/다음 일정을 구분하며 겹치는 일정도 각각 표시합니다.
- 가족 구성원 선택에 전체를 추가합니다. EVENT/REPEAT의 allMembers=true와 개별 assigneeId는 함께 지정할 수 없습니다. 전체 일정은 연결된 가족 안에서 공유되며 각 구성원 필터에도 표시됩니다. 기존 자료는 바뀌지 않습니다.
- 데이터의 JSON 필드를 그대로 저장하는 현재 구조를 사용하며 별도 데이터베이스 마이그레이션은 없습니다. 서버 입력 검증은 전체 선택을 일정에만 허용합니다.
- 부모 전용 학원비, 밝게/어둡게, 노토 산스 고정과 기존 UI78~80 동작을 유지합니다.

화면은 사용자가 첨부한 세로 시간표를 바탕으로 기존 아이하루 색상·카드·간격·상단과 하단 구조에 맞춰 구현합니다. 타 서비스 자산이나 로고를 복제하지 않습니다.

검증: 시간순 정렬·반복 범위·가족 전체 필터·시간 경계 단위 검사, 실제 API 저장·가족/자녀 조회·외부인 차단·작성자 권한 검사, 브라우저 달력↔시간표 등록/수정/삭제와 320/390/1440px·어두운 화면 확인.
