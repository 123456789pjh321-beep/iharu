# UI100 — 시간표 빈 시간 제거·정렬 및 일정 화면 버튼 정리

- 시간표의 표시 중인 3일/구성원 필터에서 가장 빠른 시간 지정 일정부터 눈금과 등록 칸을 표시한다. 분 단위 시작(예: 08:20)도 유지한다.
- 종일 일정은 시작 시간 계산에서 제외하며 상단에 유지한다. 시간 일정이 없는 날은 09:00부터 표시하고, 등록 화면에서 더 이른 시간도 입력할 수 있다.
- 일정 위치·길이·현재 시간선·스크롤·키보드 이동을 잘라낸 시작 시각 기준으로 계산한다. 현재 시각이 첫 일정보다 빠르면 시간선을 숨기고 현재 시간 버튼은 첫 칸으로 이동한다.
- 요일 제목/종일/시간 눈금 영역이 같은 스크롤바 여백을 예약해 열의 테두리가 정확히 맞도록 한다.
- 일정 제목의 크기·굵기, 배경, 왼쪽 색상선, 모서리를 달력 스타일에 맞춘다.
- 시간표와 달력의 떠 있는 + 버튼 제거. 빈 시간 칸 또는 달력 날짜 → 날짜 상세의 등록 버튼으로 등록하고, 편집 화면은 저장 버튼을 제공한다. 학원비·메모의 추가 버튼도 유지한다.
