# UI136 — 선택 대화방 나가기

기준 버전: 운영 UI135 (`69809778c433feed34c77f17536144d06fcba7fe`).

## 적용 동작

- 기본 **단체 대화**는 계속 유지하며 나가기 버튼이 없습니다.
- 별도로 만든 1:1·여러 명 대화방에는 상단 **나가기**가 나타납니다. 방을 만든 사람, 초대받은 일반사용자, 어린이 모두 본인 의사로 나갈 수 있습니다.
- 나가기 확인창에서 지난 대화를 다시 볼 수 없다는 점과 작성 중인 내용이 사라진다는 점을 안내합니다. 취소하면 방과 초안이 유지되고, 통신 실패 시 같은 창에서 재시도할 수 있습니다.
- 성공하면 내 목록과 화면·대화 캐시에서 방이 사라지고 기본 단체 대화로 돌아갑니다. 다른 탭·기기에서도 목록 새로고침/약 5초 간격 갱신으로 반영됩니다. 서버 권한은 즉시 차단됩니다.
- 나가기는 그룹 연결 해제가 아닙니다. 다른 참여자의 기존 대화는 유지되며 두 명 이상 남아 있으면 계속 대화할 수 있습니다. 한 명만 남은 방은 읽기 전용이지만 그 사람도 나갈 수 있습니다.
- 나간 사람은 이전 방의 목록·검색·메시지 조회·수정·삭제·전송 권한을 잃고 새 알림을 받지 않습니다. 아직 발송되지 않은 대기 알림도 전송 직전 참여 권한을 다시 검사해 제외합니다.
- 같은 상대와 다시 대화하려면 새 방을 만듭니다. 이전 방 참여를 복구하지 않으며 새 방에 과거 대화가 나타나지 않습니다. 중복 요청 재시도도 나간 사람을 복원하지 않습니다.

## 적용

운영 DB를 먼저 마이그레이션한 뒤 이 버전의 앱을 배포합니다. 애플리케이션의 기준 경로는 `db/migrations/`이며 `supabase/migrations/`는 동일 내용의 사본입니다. 두 파일을 같은 DB에 수동으로 중복 실행하지 않습니다.

기존 방·메시지·그룹 연결은 삭제하거나 일괄 변경하지 않습니다. 새 열은 NULL로 추가되며 사용자가 나가기를 확인할 때 해당 참여자 행만 기록합니다. 보안 함수 소유자·고정 search_path·강제 RLS를 유지하고 런타임의 구버전 함수 직접 실행을 차단합니다. DB 변경을 취소해 나간 참여자를 다시 활성화하는 롤백은 사용하지 않습니다.
