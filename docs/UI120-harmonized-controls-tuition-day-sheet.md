# UI120 — 공통 컨트롤 정돈과 학원비 날짜별 목록

- 사용자 필터와 저장 버튼은 시간표·달력·학원비에서 동일한 높이 40px, 한 줄 배치를 사용합니다.
- 저장 버튼은 선택한 첫 이름과 나머지 인원 수(예: 서준 외 2명), 저장 상태를 표시합니다. 접근성 이름과 툴팁에는 전체 선택 이름을 유지합니다.
- 필터는 가용 폭에 들어가는 완전한 버튼만 표시합니다. 나머지는 +N명 버튼에서 전체 가족 선택창으로 연결합니다. 반쯤 잘린 버튼·가로 스크롤에 의존하지 않습니다. 다중 선택과 계정별 저장 방식은 그대로 유지합니다.
- 사용 안내와 밝게·어둡게를 하나의 40px 박스로 묶습니다. 내부 버튼은 32px로 맞추고 오른쪽 현재 시간 박스도 40px로 정렬합니다.
- 작업실 로고는 가족을 표현하는 겹친 아치와 작은 해로 변경합니다. 비취색/황동색을 사용하며 어두운 화면에서는 밝은 비취색으로 표시합니다.
- 학원비 날짜를 선택하면 해당 날짜의 필터된 납부 목록·합계가 먼저 열립니다. 그 안에서 상세·수정 또는 등록을 진행합니다. 빈 날짜도 목록창에서 안내와 등록 버튼을 제공합니다.
- 달력 아래의 중복 목록은 제거합니다. 월 전체 목록은 내역 탭에서 유지합니다. 월말·윤년 반복 납부일은 기존 서버 계산을 그대로 사용합니다.
- 메뉴별 안내도 새 선택창과 날짜별 학원비 흐름에 맞게 수정합니다.

검증 범위: 320/390/500/820/1440px에서 버튼 경계·높이·한 줄 배치, 가족 선택창의 키보드·ESC·초점 복귀와 다중 선택, 메뉴별 저장, 학원비 날짜별 목록·빈 날짜·등록·수정·월말 반복·중복 목록 제거, 상단 그룹·시간 높이와 테마 동작. DB와 API 변경 없음.
