# UI128 비회원 진입과 필요한 순간 로그인

기준일: 2026-11-10. 대상: myiharu.com. 복구 기준: UI127 `afa166beab10a5001d0631254144410e7d44e192`.

## 진입 정책

루트 주소는 시간표로 연결됩니다. 비회원에게는 실제 시간 눈금·달력·공휴일·안내 메뉴를 제공하며 다른 사람의 일정이나 가상 가족 데이터를 표시하지 않습니다. 소개 화면의 시작 버튼도 시간표 둘러보기로 연결합니다.

| 구간 | 비회원 동작 | 로그인 후 |
|---|---|---|
| 시간표·달력 탐색 | 바로 표시, 날짜·월·보기 이동 허용 | 본인의 자료와 허용된 가족 공유 자료 표시 |
| 시간표 빈 시간·달력 날짜 입력 | 현재 화면 위 로그인 창 | 선택한 날짜·시간의 입력창을 열기 |
| 가이드·공지·블로그·서비스 소개·화면 설정 | 바로 열기 | 같은 탐색 기능 유지 |
| 대화·학원비·메모 | 기능 안내 화면 위 로그인 창 | 계정 권한으로 자료 조회·사용 |
| 내 계정·가족·알림·개인정보 관리 | 개인 화면을 실행하기 전에 로그인 창 | 본인 계정의 접근 가능 화면 표시 |
| 관리 화면 직접 접근 | 계정 확인 로그인 창 | 기존 서버의 관리자 권한 검사 유지 |
| 이용약관·개인정보처리방침 원문 | 로그인 없이 읽기 | 개인 동의·요청은 계정 확인 후 |

모바일은 아래에서 올라오는 창, PC는 중앙 창입니다. 취소·Escape·뒤로 가기는 창을 닫고 현재 날짜·월과 탐색 상태를 유지합니다. 로그인 후 입력창을 열어도 저장·전송·초대·결제 등은 자동 실행하지 않습니다. 로그아웃 후에는 비회원 시간표로 돌아갑니다.

학부모와 자녀는 기존의 서로 다른 로그인 API를 사용합니다. 자녀의 학원비 접근 제한, 이메일·본인 확인, 약관 확인, 가족별 공유 범위와 관리자 권한 검사는 그대로 적용합니다. 추가 확인이 필요한 로그인은 기존 계정 확인 절차로 연결합니다.

- 아이하루에서는 공개 부동산 정보와 달리 가족 자료가 개인 정보이므로 공개되는 것은 빈 작업 화면·공휴일·서비스 안내입니다. 본인·가족 정보의 공개 범위를 확대하지 않습니다.

## 인증·복귀 처리

- 로그인 대상은 허용된 앱 경로만 받습니다. 외부 주소, 프로토콜 상대 주소, 쿼리·해시가 섞인 임의 복귀 주소는 거부합니다.
- 복귀 정보에는 기능·날짜·시간만 15분 동안 보관합니다. 암호·메시지·제목·가족 식별자·저장 요청을 보관하지 않습니다. 취소 시 제거하고 입력창에서 한 번만 소비합니다.
- 이메일과 자녀 로그인은 창 안에서 이어지고, 소셜 로그인은 기존 인증 제공자의 리디렉션 후 원래 기능으로 돌아옵니다. 같은 출처의 임시 복귀 정보를 이용합니다. 저장소를 사용할 수 없으면 현재 페이지 안에서만 복귀하며 외부 인증 후에는 안전한 대상 화면으로 이동합니다.
- 인증 상태를 확인하지 못한 네트워크·서버 오류는 재시도 화면으로 표시합니다. 확인 실패를 임의로 비회원이나 로그인 성공으로 처리하지 않습니다.
- 비회원은 권한 확인용 `workspace.me` 외 개인 일정·대화·알림 폴링을 시작하지 않습니다. 기존 서버 API·쿠키·DB 접근 제어와 CSRF 검사는 유지합니다. DB 마이그레이션·추가 환경변수는 없습니다.
