# UI131 — 대화방 버튼과 그룹 정보 높이 정리

기준: UI130 `33b12d3707097635c8df735d53e7ccef69fb224b`, 2026-11-10 KST.

## 변경

- 대화방 선택 버튼의 보조 문구를 툴팁·접근성 이름으로 옮기고, 화면에는 방 이름을 한 줄로 표시한다. 버튼 높이는 40px이다.
- 상단의 별도 `대화방` 제목을 삭제하고 생성 버튼을 `+ 대화방`으로 줄인다. 대화방 선택과 생성 버튼을 같은 줄에 배치한다.
- 대화 내용 위의 중복된 `단체 대화` 제목을 삭제한다. 그룹명 또는 선택한 대화방 이름과 참여 인원만 한 줄로 표시한다.
- 그룹 정보·대화 아이콘·검색·참여자 버튼을 40px 높이로 맞춘다. 좁은 화면에서 긴 이름은 말줄임으로 표시한다.
- 비회원 샘플에도 같은 제목·버튼 문구를 적용한다. 대화방 생성 창의 제목과 접근성 이름은 행동을 설명하는 기존 문구를 유지한다.
- 대화방 생성·전환·메시지 저장·참여자 권한·로그인 흐름은 기존 기능을 사용한다. DB 변경은 없다.

## 검증

- 타입 검사와 프로덕션 빌드 통과.
- 기존 대화방 브라우저 검사에서 중복 제목 대신 현재 대화방 정보를 확인하도록 선택자를 갱신했다.
- 모바일·PC·낮은 가로 화면과 그림 메시지 입력 회귀는 전용 CI 결과로 확인한다. 전체 E2E의 기존 실패와 관련 검사 통과를 구분한다.
