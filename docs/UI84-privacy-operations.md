# UI84 운영 반영 검토 (2026-11-08)

## 구현
- 달력 구성원 필터 높이를 고정해 월간/주간 격자와 겹치지 않도록 수정. 모바일 수평 필터 유지.
- 로그인 장식 문구·중복 자녀 링크 제거. 이메일·플랫폼 / 아이디 로그인 유지.
- 운영 위치 메뉴·오늘 지도·자녀 위치 버튼·위치 동의 선택 숨김. /location은 /today로 이동. 기존 위치 데이터 삭제는 수행하지 않음. 공개 테스트 모드는 계속 차단.
- 최고관리자 전용 운영·개인정보: 운영자/책임자/문의 주소, 사업자 해당 정보, 약관·처리방침·아동 안내·위탁·국외 이전·보유/파기 기준 초안 입력, 내부 검토 메모, 미리보기, 저장/게시 사유와 게시 이력.
- 실제 운영자 정보 미입력 상태에서는 초안 유지. 필수 정보 없는 게시 차단, 게시 시 최근 본인 인증, 게시본 불변, 변경 시 새 버전.
- 공개 법적 고지와 회원별 버전·시각 확인 기록. 게시 후 성인 회원의 새 자료 등록/수정·대화 전송·가족 참여/초대 시 서버와 DB에서 현재 버전 확인. 조회·본인 자료 삭제·권리 요청은 계속 허용.
- 회원/자녀 본인별 개인정보 요청: 열람, 정정, 삭제·탈퇴, 정지, 철회, 법정대리인 확인, 문의. 관리자는 검토/답변/상태를 기록. 접수/상태 변경은 실제 삭제 수행을 뜻하지 않음.
- private 스키마·강제 RLS·최소 함수 권한·실시간 세션 검사·Origin 검사·입력 제한·요청 제한·변경 이력·경합 방지 적용.

## 게시 전 관리자가 입력/검토할 내용
사용자 요청에 따라 별도 질문 없이 관리 화면에 입력 기능을 제공했다. 현재 게시된 약관/개인정보처리방침은 없으며 모든 초안은 검토 대상이다. 가입과 기존 서비스를 임의 중단하지 않는다.
1. 실제 운영자명, 개인정보 보호책임자, 공개 문의 이메일; 사업자 주소/등록번호는 해당 시.
2. 수집 항목별 목적/법적 근거/보유 기간 및 파기; 계약 이행 처리와 별도 동의 처리 구분.
3. 실제 계약 수탁자 및 하위 처리자, Vercel 함수/로그·Supabase·메일/SMS의 처리 국가와 국외 이전 요건. DB 서울 리전만으로 국외 이전 없음을 단정할 수 없음.
4. 만 14세 미만의 법정대리인 동의 확인 수단과 증빙 보관·철회. 현재 가족 승인번호, 부모 확인 체크박스, 공개 문서 확인 기록은 적법한 법정대리인 확인 완료를 대체하지 않음. 신규 아동 온보딩 연결 및 기존 계정 전환은 후속 필수 검토.
5. 데이터 열람·삭제/탈퇴의 실제 실행·백업 파기와 결과 검증, 보유기간 자동 파기, 접근기록 보관/정기 점검, 사고 통지/신고 담당. 이번 패치는 요청·처리 기록 관리이며 자동 삭제 완료를 보장하지 않음.
6. 기존 레거시 가족 API, 아동 계정·별도 목적 동의까지 포괄하는 동의 적용 범위를 후속 정비. 이번 버전 확인은 직접 작업실의 성인 쓰기에 적용.
7. 유료 구독/광고/영문 서비스 도입 시 환불·전자상거래·표시광고·아동/해외 개인정보 검토 별도.
