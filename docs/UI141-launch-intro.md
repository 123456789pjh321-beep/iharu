# UI141 — 아이하루 시작 화면

첫 진입 시 기존 iHaru 글자 로고 아래에 **가족의 하루를 한곳에** 문구가 나타납니다. 이어서 시간표, 가족 달력, 가족 대화를 나타내는 세 카드가 차례로 표시됩니다.

- 앱이 먼저 준비되면 약 1.15초에 걸쳐 소개와 화면 전환을 마칩니다. 앱이 아직 로딩 중이면 준비 상태를 계속 표시합니다.
- 한 탭에서 처음 진입할 때 소개합니다. 같은 탭의 새로고침은 로고와 로딩 상태를 표시하며, 앱 안의 메뉴 이동은 기존 화면 전환을 사용합니다.
- 어두운 화면 설정을 첫 표시부터 반영합니다. 움직임 줄이기가 켜져 있으면 정적인 화면을 보여주고 실제 화면이 준비되는 즉시 전환합니다.
- 시작 화면은 HTML과 CSS로 표시합니다. 새 이미지나 글꼴을 내려받지 않으며 기존 로고 윤곽선을 사용합니다.
- 앱 로딩이 지연되면 기존 로딩·오류 화면으로 이어집니다. 앱 파일이 로드되지 않으면 다시 시도할 수 있습니다.

## 적용

웹 빌드 변경으로 배포합니다. 설치형 웹앱과 Android TWA가 여는 웹 화면에도 같은 HTML이 적용됩니다. DB 마이그레이션과 별도 환경변수는 없습니다.

## 검증

- 프로덕션 빌드, 단위·API 검사 321개, 시작 화면 전용 Chromium 검사 8개 통과
- 320px 모바일, 1440px 데스크톱, 다크 모드에서 첫 화면 렌더링 확인
- 비로그인 진입 검사 12개 중 11개 통과. Google 인증 페이지에서 뒤로 돌아올 때 브라우저 캐시 복원을 기대하는 검사 1개는 동일 환경의 변경 전 main에서도 실패
