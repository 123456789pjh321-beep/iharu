# UI105: 앱 시작 시간표·표 하단 마감선

- 일반 앱 진입 `/`와 과거 설치 앱의 `/today`는 `/timetable`로 이동한다. 로그인 전에는 인증 화면, 로그인 후에는 시간표를 표시하며 기존 계정 확인 절차는 유지한다.
- 설치 앱의 `start_url`은 `/timetable`로 유지한다. `launch_handler.client_mode`는 `navigate-existing`으로 지정해 지원 브라우저에서 앱 아이콘으로 다시 실행할 때 기존 창도 실행 주소로 이동한다. 지원하지 않는 브라우저는 기존 기본 실행 방식을 사용한다.
- 연결 오류 안내의 복귀 링크도 시간표로 통일한다. 사용자 자료를 캐시하지 않는 정책은 유지한다.
- 시간표 각 요일 칸의 맨 아래에 기존 격자색의 1px 안쪽 가로선을 표시한다. 시간 표시 열은 비워 두고, 칸 높이와 일정 위치는 바꾸지 않는다. 마지막 표시 시각은 기존 정시 계산을 그대로 사용한다.
- 브라우저 인증 흐름의 복귀 경로에 `/today`, `/today/timetable`를 추가하고, 연결 오류 안내의 시간표 복귀 링크를 검사한다.
- 실제 기기의 설치 앱 실행 확인은 별도 필요하다.

## 고정 반복 시간표와 등록 오류 안내

- 화면은 현재 주의 일~토 요일로 고정한다. 좌우 스와이프·트랙패드 주 이동·전환 애니메이션·주 날짜 선택기를 제거한다. 달력의 일간 보기에는 기존 이동 기능을 유지한다.
- 시간표 편집에서 반복 시작일과 종료일을 제거한다. 가족 구성원은 단일 선택 버튼(키보드를 지원하는 네이티브 라디오)으로 고른다. 요일은 가족 구성원 바로 아래에서 선택한다.
- REPEAT는 날짜 제한 없이 요일로 조회·표시한다. 기존 원본의 날짜 메타데이터는 일괄 수정하지 않으며 새 등록·수정 시 종료일을 저장하지 않는다. 내부 date는 호환용 메타데이터이며 반복 조건이 아니다.
- 달력 EVENT와 학원비 FEE의 날짜·반복 기간은 그대로다. 기존 작성자 권한·공유 해제·버전 충돌·업데이트 표시도 유지한다.
- 클라이언트와 서버에서 같은 입력 검증을 사용한다. 요일 미선택·잘못된 종료 시각은 해당 항목을 알려주고 입력한 값을 유지한다.
- 20261108152902_fixed_weekly_timetable.sql을 배포 전에 적용한다. 기존 자료 변경이나 삭제는 없다.
- 통합 검사에 09:00–16:20 유치원 등록, 요일 누락, 과거/미래 월 조회, 이전 종료일이 있는 원본, 가족 공유와 작성자 수정 권한을 포함한다.

## 확인 결과

- `npm run check`: 전체 198개 테스트, 클라이언트/서버 타입 검사, 배포 빌드 통과.
- 실제 API 및 PostgreSQL 통합 테스트에서 자녀를 대상으로 한 유치원 09:00–16:20 등록과 기간 없는 조회를 확인했다.
- 브라우저 E2E는 시나리오를 갱신했으나 Chromium 실행 시 환경의 소켓 권한 제한으로 시작하지 못했다. 실제 설치 앱/휴대폰 화면을 검증했다고 간주하지 않는다.
