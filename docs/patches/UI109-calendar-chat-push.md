# UI109 · 달력·대화 알림 및 공휴일 달력 구분선

## 변경

- 더보기의 메모를 알림설정으로 교체. 기존 메모 및 직접 접근 경로는 보존.
- 계정별 달력 등록·변경·삭제 / 달력 미리 알림 / 새 대화 수신 설정. 이 기기의 연결·해제·시험 알림 제공.
- 미리 알림 0·5·10·30·60분·1일·1주. 한국 시간, 종일 일정 오전 9시 기준. 달력과 같은 매일·매주·매월·매년 및 월말·윤년 규칙 적용.
- 시간표·학원비·메모는 푸시 대상 제외. 본인이 작성한 변경 알림은 제외하되 자신의 달력 미리 알림은 수신.
- 기본 알림은 본문을 숨김. 내용 미리 보기를 켠 경우에만 일정 제목·대화 텍스트 제공.
- 서비스 워커가 백그라운드 알림 및 동일 도메인 메뉴 이동 처리. 다른 계정의 알림 내용 노출 방지, 로그아웃 시 구독 해제·화면 알림 닫기.
- Android TWA 알림 위임 서비스와 Android 13 이상 권한 요청을 연결. 버전 1.1.0(3).
- 공휴일이 있는 주의 셀 최소 높이 중복을 제거하고, 배경보다 위에 행 구분선을 그려 하단 선 누락 수정.

## 운영

1. 두 `20261109` 마이그레이션 적용. 새 테이블은 private schema + 강제 RLS, app_runtime 직접 접근 불가.
2. 서버 환경변수 `PUSH_VAPID_PUBLIC_KEY`, `PUSH_VAPID_PRIVATE_KEY`, `PUSH_CRON_SECRET` 설정. 브라우저에는 공개키만 제공.
3. 작업자 비밀키의 SHA-256만 `workspace_push_config`에 기록. 같은 비밀키를 Vault의 `iharu_push_cron_secret`으로 저장. 저장소에는 비밀키를 넣지 않는다.
4. 즉시 발송은 Vercel waitUntil, 미리 알림·재시도는 Supabase cron이 1분마다 호출한다. 오래된 기존 일정/대화를 알림으로 소급하지 않는다.
5. 구독·세션·현재 가족 연결·설정·읽음 상태·일정 버전을 발송 직전에 재확인한다. 404/410 구독 해제, 제한된 지수 재시도, 임대/중복키 적용. 전달 보장은 at-least-once이며 네트워크 경계의 완전한 exactly-once는 보장하지 않는다.
6. 발송 대기 최대 15분, 발송 이력 7일, 비활성 구독 30일 보관 후 정리. 가입 여부와 무관하게 자동 권한 요청·자동 구독하지 않는다.

## 검증 범위

- 격리 PostgreSQL: 부모·자녀 세션, 가족 범위, 읽음 제외, 로그아웃, 다른 계정으로 기기 재연결, 일정 버전, 달력 반복일, 미리 알림 중복, 구독 만료, 재시도, private DB 권한.
- 서비스 워커: 알림 표시, 메뉴 이동, 외부 URL 차단, 계정이 바뀐 경우 본문 숨김, 만료된 알림 제외.
- Android CI: Manifest 및 런타임 회귀 검사, AAB/APK 빌드·lint, API 28/36 에뮬레이터 실행.
- 실제 사용자 기기에서 앱을 종료한 상태의 푸시 수신은 업데이트 설치 후 시험 알림으로 확인해야 한다. 서버의 push 서비스 접수 성공과 실기기 수신은 구분한다.
