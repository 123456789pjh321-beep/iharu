# UI119 — 메뉴별 사용 안내와 한 줄 사용자 필터

- 시간표·달력·대화·학원비·가족 관리·내 계정·알림설정에 맞는 사용 안내를 각각 작성했습니다. 자녀의 가족 관리/계정 안내는 보호자 화면과 분리합니다.
- 안내 완료 여부는 사용자·메뉴별로 저장합니다. 전체메뉴에서 안내를 다시 열어도 현재 메뉴를 유지하며, 닫기/ESC 후 상단 안내 버튼으로 초점이 돌아옵니다.
- 작업실의 큰 사각형 로고를 파란 심볼과 작은 iHaru 워드마크로 바꿨습니다. 공개 소개/로그인 화면의 브랜드에는 영향이 없습니다.
- 현재 시간 버튼은 사용 안내와 테마 선택 다음, 타이틀바 맨 오른쪽에 둡니다. 현재 시간 위치로 이동하는 동작을 유지합니다.
- 시간표·달력·학원비의 공통 사용자 필터와 첫 화면 설정 버튼을 모든 화면 크기에서 한 줄로 정렬합니다. 별도 ‘첫 화면 이름’ 행은 제거했습니다.
- 설정 버튼 자체에 선택한 이름과 저장 상태를 표시합니다. 작은 화면은 ‘설정됨/저장’으로 줄이고 전체 이름과 동작은 접근성 이름/툴팁에 제공합니다. 이름이 길면 버튼 안에서만 줄임표로 표시합니다.
- 이름 목록만 가로 스크롤되며 저장 버튼은 같은 줄 오른쪽에 유지됩니다. 키보드로 화면 밖의 이름에도 접근할 수 있습니다. 펼치기 버튼은 없습니다.
- 계정별·메뉴별 다중 선택 저장 API와 데이터 구조는 변경하지 않습니다. DB 마이그레이션은 없습니다.

검증: 프로덕션 빌드, 메뉴별 안내 열기/완료/재열기/ESC 초점 복귀, 보호자·자녀 안내, 320/820/1440px 필터 한 줄/스크롤/저장 버튼 배치, 현재 시간 오른쪽 배치와 이동, 다중 선택 저장·재접속·계정 분리·저장 실패 처리를 확인합니다.
