# UI79 — 기능 영역 간격 · 달력 슬라이드

UI78 운영 버전(`75f26fec`)에 이어 적용하는 화면 개선입니다.

- 화면 바깥 여백 없이 전체 폭을 사용합니다. 일정·위치·대화 등 서로 다른 기능 사이에 모바일 16px, 넓은 화면 24px 간격과 옅은 구분 배경을 적용합니다.
- 기능 제목과 내용은 16px, 기능 내부의 위아래 여유는 모바일 20px·넓은 화면 24px로 정리합니다. 학원비·메모·가족 관리·계정·달력 도구·대화 입력 영역에도 같은 간격 체계를 적용합니다.
- 달력은 이전/다음 월·주, 좌우 스와이프, 가로 트랙패드, 월 선택과 오늘 이동에 따라 방향에 맞는 280ms 슬라이드를 보여줍니다. 날짜 그리드만 이동하며 제목·검색·내비게이션은 고정됩니다.
- 연속 전환 시 이전 애니메이션을 취소하고 최신 기간으로 이어갑니다. 이전 달의 시각적 복사본은 inert/aria-hidden으로 입력과 접근성 탐색에서 제외하며 전환 종료·페이지 이탈 시 제거합니다.
- 기기 또는 앱의 ‘움직임 줄이기’ 설정을 존중합니다. 세로 스크롤과 날짜/일정 직접 편집을 유지합니다.

간격 참고: [Atlassian Spacing](https://atlassian.design/foundations/spacing)의 8px 기반 간격 체계 및 관련 기능을 가까이 묶는 원칙. 실제 적용 수치는 아이하루의 화면 밀도에 맞춰 조정했습니다.
