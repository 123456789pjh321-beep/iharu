# UI102: 시간표를 첫 화면으로

- 보호자의 하단 주 메뉴: 시간표 → 달력 → 대화 → 학원비 → 더보기.
- 오늘 메뉴를 주 메뉴와 더보기에서 제외한다. 기존 /today 주소는 이전 링크 호환을 위해 남긴다.
- 사이트 루트, 로고, 이메일·소셜·휴대폰·자녀 로그인 및 설치 앱 시작 주소는 시간표로 연결한다. 추가 인증이 필요한 세션은 계정 확인 절차를 유지한다.
- 자녀의 학원비 접근 제한은 유지하며 가족 관리·메모·계정 설정은 더보기에서 이용한다.
- 소셜 로그인은 /timetable을 고정 콜백 허용 목록에 추가하고 진행 중인 로그인 호환을 위해 /today를 유지한다.

## 시간표 마감 시간과 표 정렬

- 상단의 ‘〈 오늘 〉’ 이동 UI를 제거한다. 날짜 선택기와 좌우 스와이프로 주를 바꾼다.
- 표시 중인 주·구성원의 시간 일정 범위는 UI103의 정시 규칙을 따른다. 시작은 첫 일정 2시간 전을 정시로 내리고 끝은 마지막 종료 + 1시간을 정시로 올린다. 빈 주는 09:00–18:00이며 달력 일간의 표시 범위는 유지한다.
- 예: 첫 일정 09:10 → 표 시작 07:00, 마지막 18:10 종료 → 표 끝 20:00. 키보드 이동도 표시 범위 안에 머문다.
- 표시 범위 밖 현재 시각은 빨간 선을 그리지 않는다. 최초 진입 시 현재가 범위 밖이면 표의 시작부터 보여준다.
- 날짜·요일·일정 영역이 같은 시간축 폭을 공유한다. 열 구분선은 레이아웃 폭을 차지하지 않는 우측 선으로 통일해 1px 어긋남을 제거한다.
- 시간 열 전체에서 가로선을 제거한다. 날짜 헤더 상단, 종일 행 하단, 시간 눈금 선은 일정 열에서만 그린다. 시간 글자는 투명 배경으로 표시해 선을 부분적으로 가린 듯한 끊김이 생기지 않게 한다.
