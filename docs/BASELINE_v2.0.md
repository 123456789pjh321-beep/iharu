# 아이하루 v2.0 기준 버전

상태: **검증·수정 진행 중 / 아직 기준 버전 확정 전**

## 점검 범위

| 영역 | 확인할 정상·예외 흐름 |
|---|---|
| 가입·로그인·계정 | 연령 조건, 이메일 인증, 세션 만료, 낮은 인증 수준, 재인증, 로그인 수단 오류, 복귀 경로 검증, 로그아웃 |
| 개인·그룹·초대 | 생성·수정·탈퇴·종료, 초대 만료·취소·중복 수락, 권한과 개인/그룹 자료 분리, 빠른 그룹 전환과 늦은 응답 |
| 시간표·달력·메모 | 생성·수정·삭제, 잘못된 날짜/시간, 반복·공휴일, 구성원 필터, 월 이동, 임시 글과 사진·위치, 중복 저장·네트워크 실패 |
| 가계부 | 금액·날짜 검증, 수입·지출, 월별 조회, 공유·납부 권한, 저장 재시도와 그룹 전환 |
| 대화·알림 | 접근 권한, 방 생성·탈퇴, 메시지 중복·삭제·늦은 응답, 읽음·알림, 연결 복구 |
| 관리자·개인정보 | 권한 없는 접근, 초안/게시, 계정 및 권한 변경, 로그·검색 응답 순서, 개인정보 열람·삭제 요청 |
| 공통 UI | 320~1440px 반응형, 짧은 화면, 큰 글씨·어두운 테마, 고정 상하단과 본문 스크롤, 팝업 초점·Escape·뒤로가기, 로딩·오류·빈 상태 |
| 서버·DB | 입력·권한·트랜잭션·멱등성, 실제 PostgreSQL 동시성, 오류 응답과 민감정보 노출 방지 |

## 확정 조건

- 발견 항목은 `QA_v2.0_issues.md`에 원인·수정·검증 결과를 기록합니다.
- 단위/API 검사, 타입 검사, 프로덕션 빌드, 실제 PostgreSQL 통합 검사와 전체 브라우저 검사를 통과합니다.
- 실패 검사를 단순 제외하거나 권한·개인정보 검증을 약화해 통과시키지 않습니다. 변경된 제품 정책은 현재 정책에 맞는 동작을 검증합니다.
- 외부 OAuth·메일/SMS·지도·푸시 등 실제 외부 서비스의 범위와 격리 테스트의 한계는 구분해 기록합니다.
- 통과한 소스 커밋·환경·검사 수·배포 ID를 고정하고 버전 2.0.0 및 v2.0 이름을 반영합니다.

## 기준 버전 구성

- 정식 명칭: 아이하루 v2.0. 웹/API 패키지 버전: 2.0.0.
- 더보기 하단과 `/api/health`에 같은 릴리스 버전을 표시합니다.
- 기본 7개 메뉴: 시간표, 달력, 가계부, 타임라인, 그룹관리, 대화, 더보기.
- 개인 자료는 그룹 생성·초대 수락 시 이동/공유되지 않습니다. 그룹 자료는 선택 그룹과 작성자 권한으로 제한됩니다.
- 이번 패치는 DB 스키마를 변경하지 않습니다. 기존 운영 DB 마이그레이션 이력과 비밀 설정을 유지합니다.
- Android 설치 패키지는 별도 배포 단위입니다. 이번 웹/API 기준 버전 확정은 기존 1.2.0 래퍼의 스토어 버전 변경이나 새 APK/AAB 게시를 뜻하지 않습니다.

## 검증 환경과 경계

- Node.js 24, 잠금 파일 기준 `npm ci`, TypeScript, Vite 프로덕션 빌드.
- Vitest의 격리 PGlite SQL/API 검사, PostgreSQL 17의 실제 동시성·트랜잭션·권한 검사.
- GitHub Actions Chromium에서 실제 브라우저→격리 API→DB 연결. 모바일 320/390px, 태블릿 768/820px, 데스크톱 1024/1440px 및 별도 테스트 화면 1920px/가로모드 검사.
- 개인/그룹 격리, 수락·탈퇴·취소·재발급, 날짜 경계·반복, 중복 쓰기, 지연/실패 응답, 접근 거절, 세션 만료를 포함합니다.
- 외부 OAuth 공급자·메일·SMS·지도·웹푸시의 계약/실패는 테스트 공급자·모의 응답으로 검사합니다. 타사 실제 계정의 로그인, 실제 휴대폰 수신·푸시 전달 및 Android 실기기/스토어 배포는 이 자동화 검사만으로 보증하지 않습니다.
- 운영 데이터에 테스트 계정·일정·대화·초대를 넣지 않습니다. 운영 반영 확인은 정확한 소스 SHA의 배포 상태와 읽기 전용 상태 API로 수행합니다.
