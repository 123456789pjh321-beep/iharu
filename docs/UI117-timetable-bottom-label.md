# UI117 · 밤 10시 눈금과 하단 내비게이션 겹침 수정

주간 시간표의 스크롤 높이를 고정된 화면 높이 계산에서 실제 남은 공간을 채우는 방식으로 바꾼다. 사용 안내·인원 필터·저장 영역의 높이가 달라져도 시간표가 하단 내비게이션 안쪽으로 내려가지 않게 한다.

스크롤 영역 아래에 24px 여백을 확보해 맨 아래까지 내렸을 때 밤 10시 눈금 전체가 보이게 한다. 시간별 일정 위치와 08:00~22:00 표시 범위는 유지한다. 달력 일간 보기에는 적용하지 않는다.

높이가 500px 이하인 가로 화면에서는 시간표에 최소 스크롤 높이를 주고 전체 내용도 스크롤할 수 있게 해 화면이 지나치게 납작해지지 않도록 한다.

- 수정 `web/src/timetable.css`: 주간 시간표의 높이 연결, 내부 스크롤과 마지막 눈금 여백.
- 수정 `tests/e2e/timetable-visible-hours.spec.ts`: 320/820/970/1440px 및 짧은 가로 화면에서 마지막 눈금의 위·아래 경계와 내비게이션 겹침 검사.
- 추가 `docs/UI117-timetable-bottom-label.md`: 원인·수정과 파일 목록.
