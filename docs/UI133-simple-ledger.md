# UI133 — 처음 써도 쉬운 가계부

기준: 운영 UI132 `3a4507a2c866c750c9871bf4542445c8b80380ba`.

## 적용 내용

- 가계부 CSV 저장 버튼과 다운로드 동작 삭제. 관리자 회원·로그 CSV는 별도 관리 기능으로 유지.
- 수입/지출 → 받는 돈/쓰는 돈, 수지 차액 → 남는 돈. 쓰는 돈이 더 많으면 모자란 돈으로 금액을 양수로 표시.
- 월별 합산은 기존처럼 현재 월·선택 구성원·검색에 맞는 등록 금액 기준. 받을/쓸 예정 금액은 각 카드에 표시하고 완료 기준 보조 합계는 제거.
- 분류·상태 드롭다운 제거. 달력/내역, 전체/받는 돈/쓰는 돈, 내용 검색으로 단순화.
- 지출 분류별 보기 → 어디에 쓰나요?, 완료/예정 → 받았어요·썼어요/받을 예정·쓸 예정.
- 입력창은 내용·금액·날짜와 상태를 우선 표시. 항목·결제/받는 방법·담당자·메모는 추가 정보 (선택)를 펼쳐 입력.
- 거래일 → 날짜, 첫 거래일 → 시작 날짜, 반복 종료일 → 마지막 날짜, 매월 반복 → 매달.
- 아래 문구 3개는 대체 문구 없이 삭제.
  - 날짜를 눌러 거래를 확인하거나 등록하세요. 금액 단위: 원
  - 직접 입력한 수입·지출 기록입니다. 실제 결제·송금은 이루어지지 않아요.
  - 선택한 구성원·검색 조건의 등록 금액 기준 · N건

## 호환성

- DB/API/저장 형식 및 월별 반복·완료 기록 유지. DB 마이그레이션 없음.
- 추가 정보를 펼치지 않고 저장·수정해도 선택 항목과 결제 방법·담당자·메모는 유지.
- 그룹 공유와 작성자·담당자의 권한, 어린이 접근 제한, 비회원 로그인 연결 유지.

## 검증

- 로컬 단위·API 268개 통과. TypeScript 및 프로덕션 빌드 확인.
- 브라우저 검증 및 운영 반영 결과는 완료 시 기록.
- 기존 UI132에서 기록한 달력 넘기기 사용성 실패 4건은 이번 변경 범위 밖입니다.
