# UI126 서비스 소개·약관·개인정보 고지 저장 및 법령 대조

기준일: 2026-11-09. 대상: myiharu.com. 이 문서는 구현·법령 대조 결과이며 외부 법률전문가의 적합성 인증서는 아닙니다.

## 확인한 원인과 수정

- 로그인 라우터가 루트에 설치되면서 로그인용 16KB 본문 제한이 법적 고지 API에도 적용됐습니다. 긴 한글 문서 저장 시 413 BODY_TOO_LARGE를 실제 통합 테스트에서 재현했습니다. 인증·계정 경로에만 기존 제한을 유지하고 고지에는 512KiB 전체 상한과 문서별 글자 수 제한을 적용했습니다.
- 운영 DB에는 초안이 저장되어 있었지만 처리 위탁·국외 이전·보유 및 파기 기준이 비어 POLICY_INCOMPLETE로 게시가 거절됐습니다. 저장 완료와 게시 완료를 구분하고, 빈 항목과 `[확인 필요]` 항목을 이름별로 표시합니다. API도 해당 필드를 반환하며 미확인 문서 게시를 거절합니다.
- 저장 결과가 확정되기 전에 재조회에 의존하던 흐름을 바꿨습니다. 같은 트랜잭션에서 확정된 버전·내용·시각을 반환하고 중복 제출을 잠급니다. 동시 수정은 최신 저장본과 비교한 뒤 선택하며 입력 내용은 보존합니다. 개인정보 요청 목록 실패나 처리 결과 저장이 법적 고지 편집을 초기화하지 않습니다.
- 기존 서비스 소개는 관리자 저장 내용과 연결되지 않았습니다. 별도 초안·게시 버전을 추가해 홈페이지와 앱 독서 화면에 연결했습니다. 서비스 소개 변경은 약관 동의 버전을 올리지 않습니다. 초안은 공개되지 않습니다.

## 법령·실제 기능 대조

현재 시간표·달력·대화·메모·학원비 기록·기기 알림을 기준으로 문구를 재작성했습니다. GPS 추적·실제 결제/송금 기능이 있다고 설명하지 않습니다. 면책·일방적 약관 변경을 포괄적으로 허용하지 않고 이용 제한의 사유와 이의 제기, 공유 범위, 권리 행사 방법을 정리했습니다.

개인정보 처리방침 확인과 별도 동의가 필요한 수집·이용/제공/국외 이전은 구별했습니다. 만 14세 미만 아동의 법정대리인 동의 확인은 가족 승인번호와 구별합니다. 인증 만료·요청 상태 변경을 실제 삭제라고 설명하지 않습니다. 무료 학원비 기록에 전자상거래 보존 기간을 일괄 적용하지 않았습니다.

### 운영자가 확정해야 하는 사실

1. 개인정보처리자와 책임자의 실제 성명/법인명 및 연락처 사용 권한. 기존 입력 값을 임의로 바꾸지 않았습니다.
2. 수탁 법인·재위탁 현황·업무·처리 항목·관리 감독, 실제 처리 국가와 수령자 연락처·이전 근거·거부 방법.
3. 항목별 실제 보유 기간, 탈퇴·연결 해제 시 공유 자료 처리, 삭제·백업 만료·복구 시 삭제 재적용 절차.
4. 아동의 법정대리인 동의 확인 수단과 증빙 범위·기간.

미확정 정보는 검토 초안의 `[확인 필요]` 항목으로 남깁니다. 필수 사실을 지어내 게시하지 않습니다. 기존 게시본·동의 이력은 변경하지 않습니다. 마이그레이션은 기존 기본 문구와 정확히 일치하거나 미작성인 항목만 최신 초안으로 바꾸며 직접 작성한 문서는 보존합니다.

## 관리자 사용 순서

시스템 관리 → 운영·개인정보 관리에서 문서와 사유를 입력하고 **초안 저장**합니다. 저장 상태·시각을 확인하고 게시 전 확인 항목을 확정합니다. 미리보기에서 약관·처리방침·어린이 안내를 확인한 다음, 최근 본인 인증과 검토 체크 후 **저장한 초안 게시**를 누릅니다. 서비스 소개는 위쪽의 별도 저장·게시 버튼을 사용합니다.

## 배포·검증 기록

검증 진행 중. 최종 결과와 실제 배포 식별자는 검증 완료 후 이 문서에 기록합니다.

기존 전체 E2E에는 이전 메뉴·상단바 선택자를 사용하는 알려진 실패가 있습니다. 이번 전용 검증과 기존 달력·사용성 검증 결과를 구분해 기록하며 전체 E2E 통과로 표현하지 않습니다.

배포는 DB 마이그레이션을 먼저 적용한 뒤 앱을 교체합니다. 기존 API 호출 형식은 유지됩니다. 앱을 이전 버전으로 되돌려도 기존 게시본과 동의 이력은 보존되며 DB 열과 기록을 삭제하는 역마이그레이션은 수행하지 않습니다.
