# 공통 상단바 유지

시간표·달력·가계부·타임라인의 기존 월/날짜 및 구성원 필터 디자인을 유지하면서, 공통 상단바를 콘텐츠의 스크롤·전환 효과 밖으로 옮깁니다. 하단 내비게이션처럼 같은 상단 요소가 계속 존재하고 본문만 전환됩니다.

- 날짜 선택과 구성원 필터, 기본 필터 저장은 현재 메뉴의 기존 데이터와 동작을 사용합니다.
- 전환 중 다음 메뉴가 준비될 때까지 이전 상단 모양을 유지하되, 이전 메뉴의 버튼을 누르지 않도록 비활성화합니다.
- 시간표의 선택적 위치 안내는 본문 안에 표시해 공통 상단바를 밀어내지 않습니다.
- 초대 및 로그인 컨텍스트를 유지합니다. 뒤로 가기로 메뉴를 바꾸면 이전 필터 창을 닫습니다.
- 계정/그룹이 바뀌면 이전 상단 데이터가 재사용되지 않습니다.
- 다른 메뉴에는 이 공통 상단바를 표시하지 않습니다. 숨긴 메뉴를 함께 실행하거나 새로운 API 요청을 추가하지 않습니다.
- 콘텐츠·모달·서버·DB 및 권한 정책 변경은 없습니다.

## 검증 범위

타입 검사와 빌드, 단위 테스트에 더해 브라우저에서 상·하단 DOM 유지, 메뉴별 필터와 저장, 날짜 변경, 초대 버튼, 느린 응답 중 전환, 본문 스크롤, 뒤로 가기, 320/520/1440px와 어두운 화면을 검증합니다. 기존 로딩 단일 표시·가계부·월 슬라이딩 시나리오도 함께 확인합니다.
