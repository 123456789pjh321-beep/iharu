# UI77 — 구성원별 일정과 홈 화면 정리

- 일정·반복 일정·학원비·메모 편집기에 가족 구성원 선택을 추가한다. 개인 사용 시 본인만, 연결 후 활성 가족 구성원만 선택한다.
- 대상 구성원은 자료의 작성자와 다르다. 대상을 자녀로 지정해도 수정·삭제는 작성자만 할 수 있다. 가족에서 제외된 구성원은 새 대상으로 선택할 수 없다. 기존 자료의 대상은 ‘연결 해제된 구성원’으로 표시하며 작성자는 본인으로 대상을 변경할 수 있다.
- 기존 자료에 대상 값이 없으면 작성자 본인의 자료로 표시한다. 데이터 소유자나 공유 권한을 이전하지 않는다.
- 홈: 오늘의 일정 → 위치 지도 → 대화창. 기존 바로가기 카드 대신 실제 일정 목록과 메시지 작성기를 배치한다. 홈에서는 최근 30일 대화와 오늘 발생하는 반복 일정을 조회한다.
- 상단 하위 메뉴와 모바일 주요 메뉴: 오늘 / 달력 / 대화 / 학원비. 모바일의 나머지 메뉴는 더 보기에서 접근한다. 반복 일정은 달력 화면의 일정 종류 버튼에서 접근한다.
- 명칭: 가족 달력→달력, 가족 대화→대화, 가족 관리→관리, 하루 기록→메모, 아이 위치→위치.
- 대화는 말풍선으로 표시하며 본문 중복과 이모티콘 버튼의 세로 늘어짐을 수정한다. 작은 화면에서는 이모티콘 3열, 그 외 6열을 사용하고 버튼의 최소 크기는 44px이다.
- 카카오 지도는 기존 공개 JS 키 설정을 재사용한다. 운영 홈과 위치 화면에는 예시 마커를 표시하지 않으며, 아직 실제 위치를 수집·표시하지 않는 상태임을 명시한다. 실제 GPS 전송 기능이 추가된 것으로 표시하지 않는다.
- 일정 대상은 서버 정책 함수에서 검사한다. 가족 행 잠금으로 구성원 제외와 대상 저장을 직렬화한다. 이전 내부 함수의 app_runtime 실행 권한은 회수하고 새 검증 함수만 노출한다. 기존 FORCE RLS와 작성자 전용 수정·삭제를 유지한다.

## 검증

API: 본인·연결된 가족 선택, 외부인·제외된 구성원 거부, 대상과 작성자 분리, 내부 함수 직접 실행 차단. 실제 PostgreSQL: 가족 대상 저장과 작성자 권한·제외 후 대상 검증. 브라우저: 자녀 대상 반복 일정, 홈 세 영역 순서, 메뉴명·순서, 320/390/768/1440px 이모티콘과 메뉴 배치.
