# 타임라인 콘텐츠 SNS 피드 디자인

## 디자인

- ‘새글 등록’을 민트색 작성 영역으로 표현합니다. 추가 아이콘과 짧은 안내, 사진·위치 표시로 글쓰기를 쉽게 찾습니다.
- 작성자 이니셜 아바타와 이름을 우선 보여 주고, 시각·카테고리·사진 장수·장소 유무를 보조 정보로 정리합니다.
- 작성자 아바타는 상단 구성원 색상과 맞춥니다. 실제 프로필 사진이나 새로운 사용자 정보를 생성하지 않습니다.
- 공개 범위는 아이콘과 작은 배지로 구분하고, 저장한 즐겨찾기는 아이콘으로 표시합니다.
- 제목 한 줄·내용 한 줄의 요약을 유지하고, ‘더보기’를 오른쪽의 분명한 터치 버튼으로 표현합니다.
- 날짜 구분선, 부드러운 카드 모서리, 얕은 그림자, 글자 크기·대비·간격을 정리합니다.
- 밝게/어둡게 화면 설정에 맞춰 같은 테마 색상을 사용합니다.

## 범위

첨부한 콘텐츠 영역(새글 등록·날짜 구분·게시글 목록)의 표현만 개선합니다. 월·구성원 선택, 하단 메뉴, 상세창·편집창, 데이터 저장·권한·월 슬라이딩 동작은 유지합니다.

## 검증

기존 타임라인 브라우저 시나리오로 작성·조회·수정·삭제·사진·위치·초안 복원·월 슬라이딩을 검증합니다. 320/520/820/1440px 화면과 320/520px 어두운 화면을 확인합니다.
