# 공휴일 · 날짜별 일정 · 전체 화면 등록 · 하단 내비게이션

2026-11-08. Android TWA 1.0.1과 일반 브라우저에서 같은 웹 화면을 사용한다. 네이티브 권한·서명·패키지를 변경하지 않는다.

## 사용자 동작

- 모든 화면 폭과 방향에서 오늘 / 시간표 / 달력 / 대화 / 더보기 하단 메뉴를 고정한다. 학원비·메모·가족·계정·관리 등은 더보기에서 접근하며 기존 역할 제한을 유지한다. 오른쪽 레일과 본문 오른쪽 여백을 제거했다.
- 날짜 또는 +N개를 누르면 선택한 구성원의 그날 일정 전체가 시간순으로 열린다. 일정 선택은 상세/수정, 추가는 선택 날짜가 채워진 편집 화면으로 연결된다. 시간표의 15분 눈금에서는 기존 시간 자동 입력을 유지한다.
- 일정·학원비·메모 등록/수정은 전체 화면에 열린다. 뒤로/저장은 상단에 고정하고 필드만 스크롤한다. 제목을 크게, 대상·날짜·반복 등은 간결한 행으로 표시한다. 미저장 확인, 읽기 전용 가족 자료, 중복 저장 잠금, 버전 충돌, 삭제 확인은 유지한다.
- 공휴일은 가족 필터와 관계없이 달력 월간/주간 및 일간/시간표에 표시한다. 휴일이라고 개인 일정을 자동으로 삭제하거나 휴강 처리하지 않는다.

## 공휴일 출처와 갱신

현재 확인된 2026·2027년 발표 자료를 내장한다. 한국천문연구원 특일정보의 기존 HOLIDAY_API_KEY가 설정되어 있으면 `/api/calendar/holidays?year=YYYY`가 최신 연간 자료를 읽고 최대 24시간 재사용한다. 비공휴일 기념일은 제외하고 중복 요청을 합친다. API 오류는 마지막 성공 자료 또는 발표 자료로 대체하고 5분간 재시도를 억제한다. 인증키·가족 자료는 응답에 포함하지 않는다. 미확인 연도는 UI에 미확인 상태를 알리며 음력·선거일·대체공휴일을 추정하지 않는다.

## 검증

단위 테스트: 음력 명절·대체휴일·선거일·비공휴일, 미지원 연도, API 장애/재시도/동시 요청, 인증키 비노출.
브라우저: 320px 휴대폰, 820px 태블릿, 1440px PC, 가로 844×390. 하단 메뉴 경계·본문 폭·고정 저장·전체 일정 펼치기·선택 날짜 전달·학원비 월 전달·밝은/어두운 테마. 기존 회원/일정/반복/학원비/권한/슬라이드 회귀 검사도 수행한다.

실물 삼성 기기의 키보드/접힘/안전 영역 동작은 별도 실기 검토 항목이다. 브라우저 자동 검증이 해당 실물 검증을 대체하지 않는다.
