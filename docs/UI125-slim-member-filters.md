# UI125 — 인물 필터를 더 얇게

- 시간표·달력·학원비·오늘 화면에 사용하는 공통 인물 필터의 표시 높이를 40px에서 32px로 줄였습니다. 위아래 여백을 포함한 필터 행은 56px에서 44px로 정리했습니다.
- 체크 색상 표시는 16px에서 14px로 줄이고 모서리와 글자 굵기를 가볍게 다듬었습니다. 저장·설정됨·+N명 버튼과 가족 선택창에도 같은 높이를 적용했습니다.
- 버튼 위아래의 투명한 클릭 영역으로 세로 44px의 누르기 영역을 유지합니다. 여러 줄 선택창은 클릭 영역이 겹치지 않도록 행 간격을 확보합니다.
- 필터 선택·저장과 다중 선택, 계정별 기본값·가족별 색상은 기존 동작을 사용합니다. DB/API 변경 없음.

## 검증

기존 Workspace usability·Entry date and time UI·Notification and calendar UI·App reading and calendar stability의 브라우저 검사와 빌드 결과를 이번 PR의 최종 커밋에서 확인합니다. 새 테스트는 추가하지 않았습니다.
