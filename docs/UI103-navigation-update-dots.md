# UI103: 메뉴 업데이트 점과 시간 열 정리

- 시간표·달력·대화·학원비의 아이콘 우측 상단에 7px 파란 점을 표시한다. 메모·가족 관리의 변경은 더보기와 해당 상세 메뉴에도 표시한다. 메뉴를 선택한 배경색과 구분된다.
- 가족의 등록·수정·삭제, 납부 상태 변경, 가족 연결 변경을 계정별로 기록한다. 자신의 작업은 자신에게 새 업데이트로 표시하지 않는다. 자녀에게 학원비 정보는 제공하지 않는다.
- 개인별 확인 상태는 서버에 저장되어 재로그인·다른 기기에서도 유지된다. 5초 간격과 화면 복귀 시 확인하며, 숨긴 탭과 오프라인에서는 요청을 멈춘다.
- 메뉴의 자료를 성공적으로 불러와 화면에 표시했을 때만 해당 버전을 확인 처리한다. 대화 검색·이전 대화 조회·위로 스크롤한 상태·열린 편집창은 새 대화 확인으로 처리하지 않는다. 최신 메시지로 내려오면 확인한다.
- 더보기 창만 열어서는 메모·가족 관리의 점을 없애지 않는다. 각 메뉴에서 내용을 확인해야 한다. 내용 조회 뒤 새 변경이 들어오면 이전 확인 요청으로 새 점이 사라지지 않는다.
- 배포 전 기존 기록에는 점을 일괄 생성하지 않는다. 신규 변경부터 적용한다. 계정당 메뉴별 카운터만 보관해 변경 로그가 무한히 쌓이지 않는다.
- 시간표 시간 열의 가로선과 날짜 헤더·종일 행 선을 제거한다. 일정 열에서만 선을 그린다.
- 시간표 시작: 최초 일정 시각에서 2시간 전을 정시로 내림(09:10 → 07:00). 끝: 마지막 일정 종료 + 1시간을 정시로 올림(18:10 → 20:00). 00:00–24:00 경계를 넘지 않으며 빈 주는 09:00–18:00이다. 달력 일간 범위는 유지한다.

## 배포

1. 같은 내용의 db/migrations 및 supabase/migrations/20261108144627_workspace_menu_updates.sql을 적용한다. 기존 workspace_command의 인증·법적 동의·가족 권한 검증을 그대로 통과시키는 내부 래퍼를 추가한다.
2. 서버·화면을 배포한다. 마이그레이션은 이전 클라이언트에도 호환되며 기존 일정·대화·비용 원문을 변경하지 않는다.
3. 업데이트 전용 테이블은 RLS를 강제하고 app_runtime의 직접 접근을 금지한다. API는 세션 본인 상태만 읽고 확인 처리한다.
