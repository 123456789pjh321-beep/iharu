# 타임라인 두 줄 목록·월 슬라이딩 패치

## 화면 변경

- 상단 구성원 선택의 ‘전체’ 버튼, 이전·다음 달 화살표, ‘+ 메모 작성’ 버튼을 제거합니다.
- 두 번째 첨부 화면의 전체/사진/위치/즐겨찾기 탭, 필터 버튼, 검색창, 메모 개수, 최신순 문구를 제거합니다.
- 월 선택과 구성원 선택 아래에 ‘+ 새글 등록’ 한 줄을 배치합니다.
- 목록은 제목 한 줄과 내용 한 줄, ‘더보기’로 표시합니다. 긴 글은 목록에서 말줄임합니다.
- ‘더보기’ 상세창에서 전체 제목·본문·사진·위치·태그·공유 범위를 확인하고, 즐겨찾기 및 본인 글 수정·삭제를 수행합니다. 사진 확대와 작성 중 임시 저장은 유지합니다.
- 첫 기록 전에는 같은 두 줄 형식의 샘플 2개가 표시됩니다. 샘플의 자세한 내용도 ‘더보기’에서 볼 수 있습니다.

## 월 이동

- 목록을 왼쪽으로 밀면 다음 달, 오른쪽으로 밀면 이전 달로 이동합니다.
- 기존 달력과 같은 연속 슬라이딩을 사용하며 앞뒤 한 달의 목록을 미리 불러옵니다. 사진은 상세창에서만 요청합니다.
- 마우스 드래그·트랙패드 가로 스크롤도 지원합니다. 월 제목을 누르는 직접 선택도 가능합니다.
- 세로 스크롤, 구성원 선택, 새글 등록 및 상세창 조작은 월 이동과 분리됩니다.
- 짧거나 취소된 드래그는 제자리로 돌아오고, 움직임 줄이기 설정을 따릅니다.

## 데이터 및 검증

- DB 변경 없이 현재 메모 API를 사용합니다. 기존 글·첨부 사진·공유 권한은 유지합니다.
- 검증: 타입 검사와 빌드, 모바일/데스크톱 목록·상세·사진·수정·삭제·초안 복원, 실제 터치 및 마우스 월 이동, 세로 스크롤과 터치 취소.
- 이전 기능 문서의 검색·복합 필터 설명은 이 패치의 간결한 월·구성원 선택 UI로 대체됩니다.
