# UI101: 주간 반복 시간표와 일반 달력 분리

- 시간표는 선택한 날짜가 속한 일요일~토요일 7일을 표시한다. 좌우 제스처와 이전/다음 주 버튼은 7일씩 이동하고, 같은 주의 날짜 선택은 표시 주를 바꾸지 않는다.
- 시간표는 기존 REPEAT 원본만 조회·등록·수정한다. 달력의 월간/주간/일간은 EVENT만 조회·등록·수정한다. 오늘 화면은 두 종류를 모아 보여준다.
- 시간표의 반복 시작일·종료일·요일을 유지하고, 달력 등록에서는 반복 유형 선택을 제거했다. 작성자 권한, 가족 공유, 버전 검사는 기존 API를 그대로 사용한다.
- 2026-11-08 운영 사전 점검: 활성 REPEAT 10건, 활성 EVENT 0건, 이미 삭제된 EVENT 6건. 기존 반복 일정은 복제 없이 원본 ID·기간·대상·권한을 그대로 시간표로 분리한다. 활성 일반 일정이 없으므로 달력 초기화를 위한 추가 삭제나 스키마 변경은 필요 없다. 학원비·대화·메모 및 기존 삭제 자료는 건드리지 않는다.
- 시간표의 스크롤 동작을 유지하면서 스크롤바와 여백을 숨겼다. 시간 눈금까지 가로선을 연결하고, 첫 날짜 칸의 왼쪽 세로선과 양 끝 외곽선을 제거했다.
- 공휴일은 기존 공공 데이터/검증된 연도별 대체 자료를 공통 사용한다. 주간 시간표는 좁은 칸에서도 공휴일명을 줄바꿈하고, 미확인 연도는 안내한다.
- 로그인·회원가입과 소개 페이지는 PublicHeader를 공통 사용한다. 로고·소개 메뉴·로그인·시작하기를 한 고정 헤더에 배치하고 모바일 접힘 메뉴도 공유한다. 계정 화면 밝기 설정은 입력 카드 하단으로 옮겼다.
- 서비스 소개 예시와 활용 안내·공지·블로그를 일주일 표시 및 두 메뉴 분리에 맞췄다.

## 검증

단위/API 테스트는 주 시작일·월/연도 경계·윤년, 7일 연속 일정 병합, 일반 일정 삭제 후 반복 원본 보존을 포함한다. 기존 브라우저 시나리오를 7일 제스처·메뉴 분리·공휴일·모바일 칸 정렬에 맞춰 갱신했다. 로컬 Chromium은 실행 환경 제약으로 열리지 않아 브라우저 자동화 실행 완료로 간주하지 않는다.
