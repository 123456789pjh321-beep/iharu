# 아이하루 타임라인 작성기 고도화

v2.0 기준 버전(1261b6e)을 보존하는 후속 기능 패치입니다.

## 반영 기능

- 타임라인과 작성기에 노트북 / 녹음기 / 카메라 / 스캔 / 파일 / 스케치의 6개 메뉴.
- 개인·그룹 안에서 노트북 이름으로 기록 분류 및 노트북별 조회.
- 글 서식(굵게, 기울임, 소제목, 목록, 인용, 강조, HTTP(S) 링크), 미리보기. 기존 일반 글은 그대로 표시.
- 항목별 체크리스트, 완료 개수, 하루 기록·배움·나들이·가족 회의 양식.
- 녹음 시작·일시정지·재개·완료, 5분 제한, 화면 이탈 시 일시정지, 녹음 파일 재생/다운로드.
- 후면 카메라 우선 미리보기·촬영·재촬영·확인 후 첨부. 미지원 기기에서는 OS 사진 선택/촬영 대안.
- 문서 스캔: 촬영/사진 선택, 90도 회전, 여백 자르기, 흑백·대비 보정. 사진을 분석하는 OCR·자동 모서리 검출은 포함하지 않음.
- 손가락·마우스·펜(필압) 스케치, 색·굵기·지우개·실행 취소·다시 실행, JPEG 첨부.
- PDF/TXT/MD/CSV/DOCX/XLSX/PPTX/JPG/PNG 및 MP3/M4A/WAV/OGG/WEBM/AAC 첨부. 문서는 내려받기 방식이며 임의 HTML/스크립트 실행은 제공하지 않음.
- 임시 보관 후 닫기/복원(현재 탭, 24시간). 계정·개인/선택 그룹별 키 분리. 보관 공간 부족 시 사용자에게 표시.

## 저장·권한·호환

- 사진 3장, 파일/녹음/스캔/스케치 합계 4개, 파일당 2MB, 사진+파일 원본 합계 2.8MB. API 본문 4MB 제한은 Base64 변환과 Vercel 요청 한도에 맞춤.
- 첨부는 private 스키마의 RLS 강제 테이블에 저장. 공개 객체 URL 없음. 매번 현재 사용자·선택 그룹·공유 범위를 검증하여 조회.
- 이미지 재인코딩으로 EXIF/GPS 메타데이터 제거. 위치는 별도로 선택해야 추가됨.
- 파일 이름·타입·바이트 시그니처·크기 검증, 계정 전체 첨부 용량 250MiB 한도, 메모/첨부 저장·삭제는 단일 트랜잭션.
- 구버전 저장 요청이 새 필드를 생략하면 노트북·서식·체크리스트·파일 유지. 명시적으로 빈 배열을 보낸 경우에만 제거.
- 그룹 생성/초대 수락은 개인 기록·첨부를 그룹으로 이동하지 않음. 그룹 전환 시 작성기와 장치 연결 해제.
- 기존 메모 스키마와 데이터는 유지하고 첨부 테이블/명령을 추가. 적용 SQL은 db/migrations 및 supabase/migrations에 동일하게 보관.
- 운영 DB에 적용 후 웹 배포. 웹 롤백은 기존 v2.0 커밋으로 가능하며 새 첨부 데이터는 삭제하지 않음. 구 UI에서는 새 필드가 표시되지 않을 수 있지만 저장 시 보존됨.
