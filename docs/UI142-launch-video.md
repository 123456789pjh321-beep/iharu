# UI142 — 3초 아이하루 소개 영상

기존 iHaru 로고와 “가족의 하루를 한곳에” 문구를 사용합니다. 시간표, 가족 달력, 가족 대화가 순서대로 나타나는 밝은 화면·다크 모드용 MP4를 앱에 넣었습니다. 두 파일 모두 H.264, 640 × 640, 30fps, 90프레임, 3.000초이며 음성 트랙이 없습니다.

## 진입 동작

- 탭에서 로그인 화면을 처음 열거나, 앱 안에서 처음 로그인하여 인증된 작업공간에 들어갈 때 한 번 재생합니다.
- 테스트 모드가 켜진 환경에서는 테스트 작업공간 첫 진입에서도 한 번 재생합니다. 로그인과 테스트는 각각 한 번씩 기록합니다.
- 영상 재생은 자동·무음·인라인입니다. 재생 조작과 닫기 버튼은 표시하지 않습니다. 영상이 끝나면 0.22초에 걸쳐 사라지면서 뒤에서 준비된 화면을 드러냅니다.
- 같은 탭에서 새로고침하거나 메뉴를 이동하면 다시 재생하지 않습니다. 시스템이나 앱의 움직임 줄이기가 켜져 있거나 영상 로드·자동재생에 실패하면 본 화면으로 진행합니다.
- 시간표 등에서 로그인 전에 선택한 등록 작업은 소개가 사라진 뒤 이어집니다.

## 적용

UI141 웹 패치에 이어 적용합니다. MP4는 Vite 정적 파일 경로인 `/assets/`에서 제공합니다. 별도 환경변수와 DB 마이그레이션은 없습니다.

## 검증

- MP4 두 편 모두 3.000초, 90프레임이며 음성 트랙이 없습니다.
- 프로덕션 빌드와 단위·API 검사 321개를 확인했습니다.
- Chromium으로 모바일 로그인, 테스트 다크 모드, 영상 종료, 무음·인라인과 조작 UI, 파일 오류와 움직임 줄이기, 로그인 전 선택한 시간표 입력, 테스트 본문 키보드 포커스를 검사했습니다.
- 별도 로그인 회귀 검사에서 카카오 세션 만료 후 경로와 재인증 정식 주소의 URL 기대값 두 건이 실패했습니다. 같은 환경의 변경 전 main에서도 동일했습니다.
