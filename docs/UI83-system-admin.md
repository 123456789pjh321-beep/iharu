## 동작

- 요청된 `987654321pjh123@gmail.com`의 **기존 이메일 인증 완료·정상 계정**만 마이그레이션에서 최초 최고관리자로 지정합니다. 이메일 문자열을 브라우저 권한 판정에 사용하지 않습니다.
- 기존 `관리`는 `가족 관리`로 표시하고, 최고관리자에게만 새 `관리` 메뉴를 제공합니다. 하단 5개 주 메뉴는 오늘 → 시간표 → 달력 → 대화 → 더보기를 유지합니다.
- 현황: 전체 회원·부모·자녀·연결 가족·7일 가입·정지·관리자·24시간 오류와 최근 작업을 실제 데이터로 집계합니다.
- 회원관리: 가족 카드에 호스트·부모·자녀를 함께 묶고, 가족 미연결 계정도 표시합니다. 이름·이메일·자녀 ID·가족명 검색, 유형·상태 필터, 페이지 이동과 현재 목록 CSV를 제공합니다.
- 회원 상세: 이름 변경, 이용 정지·재개, 전체 세션 종료를 지원합니다. 이용 정지는 자료와 가족 연결을 보존하고 현재 세션과 신규 자녀 로그인을 차단합니다.
- 권한관리: 인증된 정상 부모 계정에 최고관리자 부여·해제, 실제 기능의 권한 범위를 표시합니다. 권한 변경은 5분 이내 재인증이 필요하며 기존 비밀번호 재확인 기능을 화면 안에서 이용합니다.
- 이력관리: 관리자 작업의 작업자·대상·사유·변경 전후·요청 번호, 가족 연결·일정/자료 변경·로그인 세션 생성/종료와 기존 감사 이력을 조회합니다.
- 로그관리: 배포 이후의 인증·변경 요청과 실패 요청의 경로·상태·처리 시간·요청 번호를 조회합니다. 날짜/분류/검색과 현재 목록 CSV를 지원합니다. 기존 외부 플랫폼의 과거 로그를 가져온 것으로 표시하지 않습니다.
- 시간표: 마우스 좌우 드래그/터치로 전날·다음날 이동, 드래그 후 의도하지 않은 일정 클릭 방지, 세로 스크롤 유지. 오늘은 일정 유무와 무관하게 현재 시각으로 처음 이동합니다. 굵은 시각 표식, 현재 시간 이동 버튼, 현재 진행 중인 구성원·일정을 표시합니다. 이후 수동 스크롤은 자동으로 되돌리지 않습니다.

- 달력: 일정 검색창을 제거하고 시간표와 같은 전체 보기·구성원 버튼으로 월간/주간/일간을 필터링합니다. 전체 가족 일정은 구성원 선택 시에도 표시합니다.
- 학원비: 학원 이용 구성원을 기준으로 버튼 필터를 제공하고 합계·건수를 함께 갱신합니다. 월 이동 시 선택을 유지합니다. 금액은 오른쪽에 고정하고 행 여백과 메모 표시를 줄여 한 화면에 더 많은 목록을 표시합니다. 전체 메모는 상세에서 확인합니다.
- 인증 없는 기능 테스트: 로그인 안내·링크와 기존 위치/상단의 진입 링크를 제거합니다. 운영의 `/test/*` 직접 접근은 로그인으로 이동합니다. 자동 검사에 사용하는 격리된 로컬 데모에서만 예전 시험 화면을 열 수 있습니다.

## 권한과 데이터 경계

- API에서 인증·Origin·입력을 검사하고 DB 함수에서 활성 세션·이메일 인증·최고관리자 여부를 다시 검사합니다. 일반 회원이나 가족 호스트가 URL/API를 직접 호출해도 관리 데이터를 반환하지 않습니다.
- 권한은 전용 비공개 테이블에 보관합니다. 런타임 계정은 관리 테이블·조회 뷰·내부 함수에 직접 접근할 수 없습니다. SQL 경로 고정, RLS, 명시적 함수 실행 권한을 적용합니다.
- 변경 사유 필수, 동시 변경 버전 검사, 마지막 관리자 해제·자기 정지/세션 종료 보호. 감사 기록은 런타임에서 수정·삭제할 수 없습니다.
- 요청 로그에는 비밀번호·토큰·쿠키·요청 본문·대화 내용을 보관하지 않습니다. CSV는 수식으로 해석되는 값을 이스케이프합니다.
- 기존 가족 자료의 접근·작성자 편집 규칙은 유지합니다. 최고관리자 역할과 가족 호스트 역할은 독립적입니다.
