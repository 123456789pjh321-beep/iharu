# UI104: 가입 대상 선택·공통 소개 틀·달력 반복

## 회원가입과 공통 화면

- `/signup`에서 학부모와 자녀를 먼저 선택한다. 학부모는 이메일 인증, 자녀는 기존 아이디·암호·6자리 부모 승인번호 절차로 이어진다.
- 로그인과 소개 페이지의 모든 회원가입 링크는 대상 선택 화면으로 진입한다. 직접 링크 `/signup?role=parent`, `/signup?role=child` 및 가입 화면 안 역할 탭도 지원한다.
- 서비스·활용방법·공지사항·블로그·로그인·가입·계정 복구는 하나의 PublicFrame 라우트에서 상단/하단을 유지한다. 가운데만 스크롤되므로 스크롤바 유무로 상단 로고 위치가 이동하지 않는다.
- 공지 3편과 블로그 1편 추가, 기존 안내 갱신. 주간 시간표, 달력 분리와 반복, 파란 업데이트 점, 작은 그림 목록, 학원비 주 메뉴, 가입 흐름을 안내한다. 예시는 가상 자료만 사용한다.

## 시간표

- 일자 숫자 행을 없애고 요일 버튼만 표시한다. 공휴일 이름은 요일 아래, 현재 주 범위는 상단 날짜 선택기에 표시한다. 접근성 이름에는 실제 날짜를 남긴다.
- 시간 열 전체의 선 제거와 정시 범위는 UI103을 따른다. 09:10 시작 / 18:10 종료의 주는 07:00–20:00으로 표시한다.

## 달력 반복

- EVENT에 calendarFrequency를 추가: ONCE(기본), DAILY, WEEKLY, MONTHLY, YEARLY. 시간표의 REPEAT와 별개다.
- 매주는 복수 요일을 선택한다. 반복 종료일은 선택이며 종료일까지 포함한다. 종료일이 없으면 계속 반복한다.
- 매월은 시작일의 날짜를 기준으로 매달 계산하고 없는 날짜는 말일로 보정한다. 매년 2월 29일은 평년에 2월 28일로 표시하며 다음 윤년에 다시 2월 29일로 돌아온다.
- 한 원본을 보관하고 화면에서 조회 기간의 발생일만 계산한다. 수정·삭제는 전체 반복에 적용하며 편집창에서 안내한다.
- 서버 조회는 과거에 시작한 반복도 새 월/연도에 포함한다. 기존 작성자 권한·가족 공유·버전 충돌·메뉴 확인 처리·자녀 학원비 차단을 보존한다.
- 별도 migration 20261108150359_calendar_event_recurrence.sql을 UI103 뒤에 적용한다. 기존 자료를 수정하거나 초기화하지 않는다.

## 검증

- API/SQL 통합: 저장·재조회·종료·전체 수정·삭제, 가족/외부 접근, 작성자 제한, 시간표 분리, 업데이트 확인 영수증, 잘못된 반복값·기간·요일 거절.
- 날짜 계산: 매일/매주 경계, 월말과 윤년, 종료일 포함, 원본 날짜 비변형.
- E2E 시나리오: 가입 선택, 부모/자녀 전환, 공통 상하단 위치 유지, 주간 요일 표시, 새 메뉴 점. 브라우저 실행 여부는 실제 실행 결과로 별도 보고한다.
